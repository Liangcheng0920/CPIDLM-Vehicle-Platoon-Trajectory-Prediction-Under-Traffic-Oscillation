
Data Preprocessing：Folder for data preprocessing
     Extract Formation.py : Code for extracting formation data; Change `base_path` to the path where the NGSIM data is stored

     Select footage from the two vehicles: Change `base_path` to the path where the NGSIM data is stored
     
     Generate experimental data:  
               Use the data generated by `Select footage from the two vehicles.py` to directly generate the data required for the experiment. Please note that for different training strides, you will need to adjust the window size in the code accordingly. 
              The `save_path` data output path must be changed to a path that the model code can directly access.
      matlab_code:
              We recommend using MATLAB directly to process the data and build the standard dataset for model experiments. The file `matlab_code` contains the standard MATLAB data processing scripts. Simply replace the file path with the path to your project's `data` folder. First, run `fellowing_two` to obtain the files required by `Build_dataset.m`, and then run `Build_dataset.m` directly. Note that you will need to manually adjust the window length to obtain different time steps.

Comparison Model:

       The “Comparison Model” folder contains all the comparison models; in each entry, ‘ONE’ indicates a single-step prediction, while “MORE” indicates a multi-step prediction.

      The names of each code have been standardized to match the names of the comparison models in the paper.

      Comparing the execution of model code:  
                All code in the comparison model can be run independently. Please ensure that the paths to the single-step and multi-step datasets generated during the Extract Formation stage match the paths specified in the code. For example: data = sio.loadmat(‘E:\pythonProject1\data_fine_0.1.mat’)  # Please replace this with the actual name of your data file


MY_MODE: 
        This directory contains the complete CPIDLMD model code for this project, where “ONE” represents single-step forecasting and “MORE” represents multi-step forecasting.
        All code can be run independently. Please ensure that the paths to the single-step and multi-step datasets generated during the Extract Formation stage match the paths specified in the code. For example: data = sio.loadmat(‘E:\pythonProject1\data_fine_0.1.mat’)  # Please replace this with the actual name of your data file


Code Execution Order:
1. First, set up a virtual environment according to the requirements in `requirements.txt`.
2. Use the code in the “Data Preprocessing” section to build a standard training dataset. Note that you must manually adjust the prediction step size in the dataset to match that of each code file to ensure consistency.
3. Place the constructed data in a location accessible to all scripts, then run each script individually. To facilitate execution by readers, each .py file includes the model architecture, training code, testing code, validation code, and code for visualizing and saving results.
